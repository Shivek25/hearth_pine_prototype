# Hearth & Pine | Off-Grid Cabin Prototype

An interactive, nature-inspired web prototype built for a luxury off-grid cabin startup. This project serves as a high-fidelity blueprint for the final WordPress production site, focusing on a "nature-first" aesthetic and seamless user experience.

## 🌲 Project Overview

Hearth & Pine is designed to bridge the gap between rugged outdoor living and modern luxury. The prototype showcases the core user journey, from discovering unique dwellings to purchasing gift vouchers and inquiring about landowner partnerships.

### Key Pages & Features

- Interactive Home: Responsive hero section with featured cabin listings.

- Our Story: Brand narrative focusing on sustainability and the "nature-first" philosophy.

- Booking Engine (UI/UX): A streamlined modal-based booking flow.

- Gift a Stay: A dedicated portal for purchasing digital stay vouchers.

- Partner Program: An inquiry system for landowners to join the off-grid network.

- Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

### 🛠 Tech Stack

- Framework: React.js (via Vite)

- Styling: Tailwind CSS for a utility-first, performant design.

- Icons: Lucide React for clean, minimalist iconography.

- Animations: Custom CSS keyframes for fluid page transitions and modal scaling.

### 📦 Installation & Local Setup
To run this project on your local machine, follow these steps:

- Clone the repository

- Install dependencies

- npm install

- Run the development server: npm run dev

- View the app: https://hearthpinecabin.netlify.app/
